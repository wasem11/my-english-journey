MY ENGLISH JOURNEY — INTEGRATED ACADEMIES UPDATE

This update adds:
- English Academy: six interactive lessons with English-first text, optional Afghan Dari, audio playback, answers, feedback and completion tracking.
- Social Confidence: six interactive conversations about school, neighbors, pharmacies, and family.
- Updated home screen with links to both academies.
- Keeps the existing California Driving Adventure, road-sign images, saved XP, and existing AI speaking-practice route.

INSTALL
1. Back up your working project first.
2. Extract this ZIP.
3. Copy the ZIP's app and src folders into:
   C:\Users\wasem\Desktop\app\MyEnglishJourney\MyEnglishJourney
   Choose to merge folders and replace files when asked.
4. Do not delete your existing assets folder, server, or node_modules.
5. In the working project terminal run:
   npx.cmd expo start --clear
6. Open the app. On Home, choose Everyday English or Real-life conversations.

IMPORTANT
- English and social lessons are interactive, offline-ready starter content, not the full planned curriculum.
- Listen-and-repeat is NOT automatic speech recognition. The existing /practice route still needs an external AI evaluation backend for scored voice practice.
- This package does not implement payments, notifications, or a complete DMV handbook course.
- No dependencies were added. The original project was preserved.
- Please test on your Windows Expo installation and iPhone before considering this production ready.
